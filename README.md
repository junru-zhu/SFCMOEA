# SFCMOEA

Paper companion for:

> Sicheng Ma, Lixiang Zhang, Guocai Chen, Zeyu Dai, Junru Zhu, and Wei Fang.  
> “A Hybrid Clique-Based Method with Structural Feature Node Extraction for Community Detection in Overlapping Networks.”  
> *Computers, Materials & Continua*, 87(1), 2026.  
> DOI: [10.32604/cmc.2025.073572](https://doi.org/10.32604/cmc.2025.073572)

SFCMOEA combines structural feature node extraction, maximal-clique representation, and hybrid MOEA/D for overlapping community detection. The paper evaluates the method on real-world, synthetic LFR, and large-scale collaboration networks.
